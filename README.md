# Django Blog Tests

Учебный Django-проект с тестами страниц списка и детальной страницы блога.

## Возможности

- список статей и переход на детальную страницу;
- автоматическое увеличение счётчика просмотров при каждом GET-запросе к статье;
- тесты статусов, шаблонов, контента, контекста, ссылок, идентификаторов и 404;
- проверка начального значения и увеличения счётчика просмотров.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py test -v 2
```
