# Django Blog Lab 6

Учебный проект с CRUD статей и автоматическим Word-отчётом о тестировании.

## Запуск в Windows

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Откройте http://127.0.0.1:8000/. Создание, просмотр, редактирование и удаление доступны со страницы списка. Удаление требует POST подтверждения. Проект предназначен для локальной учебной работы; авторизация CRUD не реализована.

## Тестирование и отчёт

```powershell
python manage.py test -v 2
```

Django выполняет 30 тестов через `blog.test_runner.ReportingRunner`. После запуска автоматически создаются:

- `reports/lab6_report.docx` — описание работы, фактические статусы всех тестов, скриншоты и полный код тестов;
- `reports/test-results.json` — результаты в машиночитаемом формате.

`reports/test-results.txt` содержит сохранённый протокол итоговой проверки. Скриншоты в `reports/screenshots/` получены при браузерной проверке 26 октября 2026 года; при повторном запуске тестов они не переснимаются. Тесты работают с отдельной временной базой данных.

Проверяются: список и детальная страница, контекст и шаблоны, счётчик просмотров, создание, изменение, удаление, валидация, 404, 405, CSRF и экранирование HTML. Историческое поле `likes` обозначает просмотры и увеличивается при каждом открытии подробной страницы.
